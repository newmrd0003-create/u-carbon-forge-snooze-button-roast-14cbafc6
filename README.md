# Snooze Button Roast

One-line roast of an alarm clock that rings at 6 AM on a Saturday — no office/HR clichés, just a concrete image and a punchline that lands in the last words.

**Entry (161 chars):**

> My alarm went off at 6 AM on a Saturday like it had somewhere to be — it doesn't. Today's only appointment is me, this pillow, and absolutely nothing until noon.

## How to run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (UTF-8, single line, 1–200 chars) and prints its character count, validation result, and sha256. The program is deterministic: every run produces byte-identical output. Standard library only, no dependencies.
